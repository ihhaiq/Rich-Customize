# دليل الترجمة

النسخة الحالية تستخدم JavaScript داخل `tgcloud/`، وواجهة Mini App داخل `app/miniapp_static/`.

راجع ملفات الترجمة الحالية واستخداماتها قبل إضافة مفتاح. حافظ على أسماء المفاتيح والقيم الديناميكية متطابقة بين اللغات، ولا تترجم محتوى المستخدم أو أسماء الصفحات باعتبارها مفاتيح واجهة. شغّل `npm test` للتحقق من اختبارات الترجمة المتاحة.

دليل Python القديم محفوظ في [الأرشيف](archive/python-i18n-guide.md) كمرجع تاريخي فقط.
