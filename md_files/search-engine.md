# خطة محرك البحث للإيموجي والحزم

> الحالة: مؤجل للتطوير لاحقًا.
>
> الفرع المستهدف عند العودة للتنفيذ: السيرفليس.
>
> الهدف: بناء بحث سريع ومتعدد اللغات للإيموجي العادي وTelegram Custom Emoji والحزم، مع إبقاء محرر الرسائل مستقلًا عن TDLib.

## الهدف الوظيفي

يسمح البحث للمستخدم بكتابة كلمات عربية أو عراقية أو إنجليزية أو إيموجي مباشر، مثل:

- سعيد، فرحان، مبتسم، happy، 😊
- زعلان، حزين، يبچي، 😢
- معصب، غاضب، 😡
- قط يضحك
- قلب أزرق
- نار متحركة

ويعيد أفضل النتائج من الإيموجي العادي والحزمة البريميوم المضافة، ثم يمكن لاحقًا إضافة نتائج عالمية من Telegram.

## المعمارية المقترحة

المسار الأساسي:

المستخدم ← تطبيع الاستعلام ← توسيع الكلمات والمرادفات ← البحث المحلي ← ترتيب النتائج ← عرض النتائج

المسار المتقدم لاحقًا:

المستخدم ← البحث المحلي الفوري ← خدمة بحث مستقلة ← TDLib بحساب خدمة مستخدم ← نتائج Telegram العالمية ← دمج وإزالة التكرار ← تخزين العناصر المختارة محليًا

لا ينبغي تشغيل TDLib داخل العملية الأساسية للمحرر. إذا أضيف لاحقًا، يكون خدمة مستقلة حتى لا يؤدي تعطل الجلسة أو Flood Wait إلى تعطيل المحرر.

## طبقات البحث

### البحث المحلي

هو المصدر الأول ويجب أن يعمل دون أي طلب شبكي أثناء الكتابة.

يشمل:

- الإيموجي العادي.
- الحزمة البريميوم المضافة للمستخدم.
- العناصر المستخدمة مؤخرًا.
- المفضلة.
- الكلمات العربية والعراقية.
- الكلمات الإنجليزية وأسماء Unicode.
- اسم الحزمة.
- الإيموجي البديل المرتبط بـ Custom Emoji.

### البحث العالمي لاحقًا

يستخدم فقط عندما تكون النتائج المحلية غير كافية.

الخدمة المقترحة تستخدم TDLib أو MTProto بحساب Telegram مخصص للخدمة، لأن بعض عمليات البحث العامة عن الملصقات والحزم ليست متاحة للـ Bot Token.

تُرجع الخدمة أقل قدر من البيانات المطلوبة ولا تصبح مصدر الحقيقة لصفحات المحرر.

## تطبيع النص العربي

قبل البحث:

- إزالة التشكيل.
- إزالة التطويل.
- تحويل أ، إ، آ، ٱ إلى ا لغرض المطابقة.
- تحويل ى إلى ي.
- معالجة ة وه عند الحاجة في مفتاح البحث فقط.
- توحيد المسافات.
- تحويل الشرطة والشرطة السفلية إلى مسافات.
- تحويل النص الإنجليزي إلى lowercase.
- الاحتفاظ بالنص الأصلي للعرض وعدم تعديله.

مثال:

ابتسامة، ابتسامه، إبتسامة ← مفتاح بحث موحد.

## قاموس المرادفات

يكون القاموس مرتبطًا بالمفهوم أو بالإيموجي العادي، وليس بكل Custom Emoji منفردًا.

أمثلة:

- 😊 ← سعيد، فرحان، مبتسم، يبتسم، مبتهج، ابتسامة.
- 😂 ← ضحك، يضحك، مضحك، قهقهة، ميت ضحك.
- 😢 ← حزين، زعلان، يبكي، يبچي، دمعة.
- 😡 ← معصب، عصبي، غاضب، غضب.
- ❤️ ← قلب، حب، أحبك، احمر.
- 🎁 ← هدية، هديه، كادو.
- 🐱 ← قط، قطة، بسة، بسه.

يمكن إضافة قاموس عراقي فوق الكلمات القياسية من دون تعديل بيانات Telegram الأصلية.

## فهرسة Custom Emoji

لكل عنصر نخزن بيانات بحثية مثل:

- custom_emoji_id
- alt_emoji
- pack_name
- pack_title
- preview_file_id
- format
- text_color
- is_free
- keywords_ar
- keywords_en
- discovered_at

وتكون بيانات الاستخدام الخاصة بالمستخدم منفصلة:

- user_id
- custom_emoji_id
- use_count
- last_used_at
- favorite

لا نكرر بيانات الإيموجي العامة لكل مستخدم.

## فهرسة الحزم

عند إضافة حزمة:

1. التحقق من الرابط أو short name.
2. جلب بيانات الحزمة مرة واحدة.
3. استخراج جميع Custom Emoji IDs.
4. ربط كل عنصر بـ alt emoji إن توفر.
5. توليد كلمات البحث من اسم الحزمة والإيموجي البديل والقاموس.
6. حفظ الفهرس.
7. تجهيز المعاينات بشكل lazy وعدم تنزيل كل الملفات مسبقًا.

ملاحظة حالية: واجهة التطبيق المصغر مقيدة بحزمة بريميوم واحدة فقط. إذا تغير هذا القرار مستقبلًا يجب تعديل حد الحزم وواجهة التبويبات معًا.

## ترتيب النتائج

يعتمد الترتيب على Score مركب، مثال أولي:

- تطابق الإيموجي نفسه: وزن 100.
- تطابق العبارة بالكامل: وزن 90.
- تطابق كلمة بالكامل: وزن 80.
- بداية كلمة: وزن 65.
- مرادف مباشر: وزن 55.
- اسم الحزمة: وزن 35.
- عنصر مفضل: إضافة 20.
- مستخدم حديثًا: إضافة متناقصة حسب الزمن.
- كثرة الاستخدام: إضافة لوغاريتمية صغيرة.

يجب ألا يسمح Boost الشخصي لنتيجة ضعيفة بتجاوز تطابق مباشر واضح.

## الاستعلامات متعددة الكلمات

يعالج كل Token على حدة ثم يحسب تقاطع المفاهيم.

مثال:

قط يضحك

يجب أن تكون نتيجة تحتوي مفهوم القط ومفهوم الضحك أعلى من عنصر يطابق كلمة واحدة فقط.

مثال:

قلب ازرق

تُعطى أولوية لـ 💙 وما يرتبط به من Custom Emoji.

## البحث أثناء الكتابة

- البحث المحلي يعمل مباشرة.
- يستخدم debounce قصير للعمليات الأغلى.
- لا يرسل طلبًا إلى Telegram مع كل حرف.
- لا يبدأ البحث العالمي إلا بعد طول استعلام مناسب أو نقص النتائج المحلية.
- تلغى الطلبات القديمة عند تغير الاستعلام.
- تحفظ النتائج المتكررة في cache قصير المدة.

## إزالة التكرار

المفتاح الأساسي لـ Custom Emoji هو custom_emoji_id.

عند وصول نفس العنصر من أكثر من مصدر:

- نحتفظ بسجل واحد.
- ندمج الكلمات الوصفية.
- نحتفظ بأفضل بيانات معاينة.
- نرفع النتيجة إذا كانت موجودة محليًا ومستخدمة سابقًا.

## واجهة المستخدم

يبقى شريط البحث ظاهرًا داخل منتقي الإيموجي.

ترتيب الأقسام المقترح:

1. أفضل النتائج.
2. المستخدمة مؤخرًا.
3. نتائج الحزمة الحالية.
4. النتائج العادية.
5. نتائج أخرى من Telegram عند تفعيل البحث العالمي.

لا تفتح لوحة المفاتيح تلقائيًا عند فتح المنتقي.

## الأداء

- تحميل المعاينات lazy.
- حد أقصى لطلبات المعاينة المتزامنة.
- Cache للصور والملفات.
- عدم تخزين نفس Custom Emoji أكثر من مرة.
- عدم استدعاء TDLib من واجهة المستخدم مباشرة.
- وضع timeout وrate limit على خدمة البحث العالمية.
- عند فشل الخدمة العالمية يستمر البحث المحلي بلا خطأ للمستخدم.

## الأمان والعزل

- لا تستخدم حساب المطور الشخصي كجلسة TDLib.
- تستخدم جلسة خدمة منفصلة إذا أضيف البحث العالمي.
- بيانات جلسة Telegram لا تصل إلى المتصفح.
- المتصفح يتعامل فقط مع API محدود للبحث.
- لا تصبح خدمة TDLib مصدر الحقيقة لصفحات Rich Customize.
- لا ترسل محتوى الصفحات إلى خدمة البحث؛ ترسل عبارة البحث فقط عند الحاجة.

## مراحل التنفيذ المقترحة

### المرحلة الأولى

تطوير البحث المحلي الموجود حاليًا:

- توسيع القاموس العربي والعراقي.
- تحسين التطبيع.
- إضافة Scoring حقيقي بدل المطابقة البسيطة.
- دمج الإيموجي العادي مع Custom Emoji في نفس نتائج البحث.

### المرحلة الثانية

إضافة فهرس دائم لاستخدامات المستخدم والمفضلة والحديثة.

### المرحلة الثالثة

إضافة خدمة بحث عالمية مستقلة وتجربة TDLib بحساب خدمة منفصل.

### المرحلة الرابعة

دمج النتائج العالمية مع المحلية، وإضافة cache وrate limiting ومراقبة الأخطاء.

### المرحلة الخامسة

اختبارات عربية وإنجليزية ولهجة عراقية واختبارات الأداء على الهواتف الضعيفة.

## شروط القبول

يعتبر النظام جاهزًا عندما:

- يجد سعيد وفرحان ومبتسم نتائج متقاربة مناسبة.
- يجد يبچي نتائج البكاء.
- يجد الاستعلام بالإيموجي نفسه Custom Emoji المرتبط به.
- يعرض النتائج المحلية بلا انتظار شبكة.
- لا يتعطل المحرر إذا تعطلت خدمة البحث العالمية.
- لا تتكرر نفس نتيجة Custom Emoji.
- يبقى ترتيب النتائج ثابتًا ومفهومًا.
- لا تزيد ميزة البحث من زمن فتح منتقي الإيموجي بشكل ملحوظ.
